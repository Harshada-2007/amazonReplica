# 🛒 Amazon Replica – Frontend Project

This is a simple **Amazon homepage replica** built using HTML and CSS. It mimics the design and layout of the original Amazon homepage, featuring a responsive navigation bar, product categories, promotional banners, and a styled footer.

## 🔗 Live Demo  
Check it out here 👉 [Amazon Replica](https://harshada-2007.github.io/amazonReplica/)

---

## 🚀 Features
- Responsive **navigation bar** with logo, delivery location, search bar, and cart
- Image-based **product categories** and promotional banners
- Custom **CSS styling** without any frameworks
- Integration with **Font Awesome** for icons

---

## 🛠️ Technologies Used
- HTML5
- CSS3
- Font Awesome (via CDN)
